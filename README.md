# password-strength-checker

Why I built this:
I built this project to combine programming practice with an everyday cybersecurity-related problem.
I wanted to understand how different password characteristics can affect basic password strength.

Feature:
Check Password Length - Check For Uppercase Letters - Check For Lowercase Letter - Check For Numbers - Check For Special Characters - Provide A Basic Strength Classification - Give Suggestions For Improving Weak Passwords

How it works:
The program receives a password from the user and checks several basic characteristics.
It then evaluates the results and provides a simple strength classifications for improvment.

What I learned:
Conditional Statements - Loops - Functions -  Boolean Logic - Working With User Input - Basic Cybersecurity Concepts
